# OKF Homebrew Tap

Official Homebrew tap for **OKF Agent Memory** (`okf`) — the domain-neutral, Git-native persistent project memory engine for AI coding agents based on the Open Knowledge Format (OKF) v0.2.

---

## 🚀 Installation

Install the pre-compiled, zero-dependency `okf` CLI and embedded Model Context Protocol (MCP) server:

```bash
brew install okf-memory/tap/okf
```

Or add the tap first:

```bash
brew tap okf-memory/tap
brew install okf
```

---

## 🔍 Verify Installation

```bash
okf version
```

---

## 🔄 Updating

```bash
brew update
brew upgrade okf
```
